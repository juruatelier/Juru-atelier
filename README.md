# JURU ATELIER — Coming Soon

A zero-dependency static landing page for juruatelier.com.

## GitHub Pages
1. Create a new public repository (for example `juruatelier`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / root.
4. Once Pages gives you a live URL, add `juruatelier.com` under Settings → Pages → Custom domain.
5. GitHub will show the DNS records you need. Add those records in Squarespace Domains DNS settings.
6. After DNS verifies, enable **Enforce HTTPS** in GitHub Pages.

`reference-logo.png` is included only as a visual reference; the landing-page mark itself is drawn as SVG so it stays sharp on every screen.
